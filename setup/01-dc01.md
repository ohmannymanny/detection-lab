## Sysmon Installation

Sysmon provides detailed endpoint telemetry — specifically process creation
and LSASS memory access events — that feed into Wazuh for detection.

Config used: SwiftOnSecurity sysmon-config
https://github.com/SwiftOnSecurity/sysmon-config

```powershell
mkdir C:\Tools
Expand-Archive -Path "C:\Tools\Sysmon.zip" -DestinationPath "C:\Tools\Sysmon"
cd C:\Tools\Sysmon
.\Sysmon64.exe -accepteula -i sysmonconfig.xml
Get-Service Sysmon64
# Status: Running
```

## Troubleshooting Notes

**Issue:** VMs on VMnet1 have no internet access by design.  
**Fix:** Download files on host machine, drag into VM using VMware Tools
drag-and-drop (requires VMware Tools installed first).

**Issue:** sysmonconfig downloaded as .htm instead of .xml by browser.  
**Fix:** Save As → All Files → filename.xml, or use PowerShell
Invoke-WebRequest with a temporary NAT adapter for internet access.
